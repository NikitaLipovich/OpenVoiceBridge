# Проверка стенда владельцем и запись своего звонка

Все команды из корня репозитория `esp32s3_phone_stream`, ветка `phone-bringup`. Каждая пишет `PASS`, `FAIL` или `НЕ ПРОВЕРЕНО`, числа и что делать. Код выхода 0, 1, 2. Скрипты не звонят, не отвечают на звонок и не включают звук на компьютере.

**Цепочка гоалов делит этот стенд с вами.** Если идёт её серия, шаг скажет «стенд занят» и ничего не тронет. Чтобы стенд был вашим, напишите супервизору, что вы на месте (`NEEDS-OWNER`, пункт 45).

**Перед началом:** LyraT и S3-ETH включены, S3 в кабеле и в одной сети с ПК, телефон по USB, отладка разрешена, экран разблокирован. Других гарнитур на телефоне не подключать: `LyraT_Phone` должна быть единственной.

## 1. Проверить стенд

Всё подряд, около 30 минут, в конце таблица:

```
python lyrat_resend/tools/bench/owner_check.py all
```

Или по шагам, в этом порядке:

| Команда `python lyrat_resend/tools/bench/owner_check.py ...` | Что проверяет | Успех |
|---|---|---|
| `ports` | Порты, S3 по сети, телефон, приложение, никто их не держит | `PASS` |
| `firmware` | Сборка на LyraT, адрес `mac_b1`, режим `web2`. Сбрасывает плату | `PASS`. Сборка может быть новее: на стенде работает и гоал 062 |
| `stable` | 2 минуты без сбросов (#003) | `PASS` |
| `power` | Индикатор питания | Всегда `НЕ ПРОВЕРЕНО`, пока нет гоала 059 |
| `bluetooth` | Подключение после сброса, канал без звонка, кодек mSBC, отказы телефона (#001) | `PASS` |
| `audio` | Тоны в обе стороны, 10 попыток, порог 20 дБ, 8 минут | `PASS`. Обрывы (#004) этот шаг не показывает |
| `breaks` | Сбои в сторону телефона в минуту, 5 минут. Прежний разброс 0,37-0,63 | Сейчас ожидается `FAIL`: это открытый #004, его и должно быть видно |
| `uart` | Команды через S3, сбросы обеих плат, 3,5 минуты | `PASS` |
| `stream` | Запись 5 минут с тонами: потери, длительность | `PASS`. Может ждать конца шума до 15 минут |
| `mic` | Шум линии микрофона сейчас (#005), предел 400 | `PASS`. `FAIL` значит: с разговором лучше подождать |
| `rehearsal` | Вся запись на канале из приложения, без звонка | `PASS` |
| `voice` | Вы говорите, режимы до и после, описание `VOICE_CHECK.md`, 2,5 минуты | Всегда `НЕ ПРОВЕРЕНО`: судит только ваш слух |

Папка каждого шага: `goals_harness/bench_runs/owner/<время>-<шаг>/`.

Если `firmware` говорит, что на плате не `mac_b1`, вернуть:

```
python lyrat_resend/tools/bench/fw.py flash --variant mac_b1
python lyrat_resend/tools/bench/fw.py erase-bonds
python lyrat_resend/tools/bench/phone.py forget
python lyrat_resend/tools/bench/phone.py pair
```

Если `sco_probe` нет на телефоне: `python lyrat_resend/tools/android/build_apk.py --install`.

## 2. Записать свой звонок

Прямо перед звонком `python lyrat_resend/tools/bench/owner_check.py mic`, затем:

```
python lyrat_resend/tools/bench/call_record.py
```

Дождитесь строки «ЗАПИСЬ ИДЁТ», позвоните сами, на телефоне выберите гарнитуру `LyraT_Phone`, договорите. Запись остановится сама через 10 с после закрытия канала, или нажмите Enter. Если будете уводить звук с гарнитуры больше чем на 10 с, запускайте с `--only-enter`.

Файлы в `goals_harness/bench_runs/call/<время>/`, вне git. Слушайте своим плеером:

- `call.wav`: собеседник, то, что телефон шлёт в наушники.
- `mic.wav`: ваш микрофон, два канала, **до** шумоподавления и Bluetooth. Собеседник слышал не это.
- `call_summary.json`, `summary` на экране: длительность, потери, сбросы, кодек, где в файле был канал.

Сброс платы или S3, пропажа порта или обрыв канала не теряют записанного: всё остаётся в файлах, время сбоя записано тишиной, итог `FAIL` называет причину. Если упала сама команда или закрыли окно:

```
python lyrat_resend/tools/bench/call_record.py --recover goals_harness/bench_runs/call/<время>
```

Номер абонента нигде не сохраняется: строка CLIP в логе платы скрывается целиком, телефон во время записи не опрашивается.

## Не проверено

- **Настоящий звонок: цепочка их не делает (R3).** Запись проверена только на канале из приложения. Как поведёт себя настоящий звонок, покажет сводка вашей записи. Если канал не открылся: итог `НЕ ПРОВЕРЕНО`, а звук остался на телефоне.
- **Голос.** Ни один шаг не судит качество голоса: на стенде его никто не произносил.
- **Обрывы в сторону телефона в записи не видны:** `mic.wav` снят до Bluetooth. Слышит их только собеседник.
- Напряжение питания (гоал 059).
- Контроли, которым нужны руки: выдернуть USB LyraT и настоящая потеря питания во время записи. Отключить S3 от сети. Экран телефона заблокирован.

## Открытые дефекты, зелёные шаги их не закрывают

- **#004:** обрывы к телефону по 14,6 мс, около 4 в минуту против 0,37-0,63 раньше, причина не найдена, ищет гоал 062. Послушайте в разговоре, слышно ли.
- **#005:** шум линии микрофона приходит сам, минутами и часами, причина не найдена. Когда `mic` даёт `FAIL`, собеседник слышит этот шум. Подождите и повторите.
- **#003:** цикл сбросов LyraT на старте радио. Прекратился после перестановки в другой порт USB-блока, причина не разделена. Увидите в `stable`: проверьте порт и адаптер.
- **#001:** зависшая запись `bt_sco` на телефоне: канал не откроется, звонок может не перейти в гарнитуру. Перезагрузка телефона помогла один раз, но не считается решением (R17), решение ищет гоал 058.
