# Первая прошивка: один раз по USB, дальше без USB

После этой команды стенд работает по Wi-Fi через S3: прошивка обеих плат, журнал LyraT, команды, сброс, проверки
`owner_check.py` и запись разговора идут по сети. Кабели USB от плат к ПК можно отключить, платы питать от USB-блока или
аккумулятора. Сопряжение LyraT с телефоном сохраняется. Команды из корня репозитория `esp32s3_phone_stream`.

## 1. Что подготовить

- В `lyrat_resend/main/wifi_secrets.h` — имя и пароль сети Wi-Fi 2,4 ГГц, той же, где ПК (шаблон
  `wifi_secrets.h.example`). Файл в git не попадает. Если уже есть `s3_eth_bridge/main/ota_secrets.h`, берётся он.
- LyraT и S3 включены и подключены к ПК по USB: LyraT своим кабелем (CP210x), S3 своим (USB ESP32-S3). Провода S3-LyraT
  на месте (`S3_TAP.md`).
- Мониторы портов (ESP-IDF, терминал) закрыты.

## 2. Одна команда

```
python lyrat_resend/tools/bench/first_flash.py
```

Около 10 минут: соберёт обе прошивки, прошьёт по USB сначала S3, потом LyraT, дождётся S3 в Wi-Fi и LyraT за ней,
проверит токен и версии, 20 секунд почитает журнал по сети. Каждый шаг печатается строкой `OK` или `СБОЙ` с причиной.
Если `ota_secrets.h` не было, он создаётся сам с новым токеном; значения нигде не печатаются.

## 3. Что увидеть

Последние строки:

```
Итог: обе платы прошиты, S3 в сети Wi-Fi, LyraT отвечает через неё, журнал идёт по сети.
USB можно отключать.
```

Только после строки **«USB можно отключать»** отключайте кабели. Если вместо неё «НЕ готово» — причина в той же строке:

| Причина | Что сделать |
|---|---|
| секреты: нет или шаблонные значения | заполнить `wifi_secrets.h`, повторить |
| порты: не найден / занят | подключить кабель / закрыть монитор, повторить |
| сеть: S3 не ответила по Wi-Fi | имя и пароль сети в `ota_secrets.h`, сеть 2,4 ГГц, ПК в той же сети |
| сеть: LyraT за ней не отвечает | питание LyraT, провода UART S3-LyraT (`S3_UART.md`) |

Повторный запуск безопасен. Запись прогона: `goals_harness/bench_runs/first_flash/<время>/` (вне git), там же копия
прежних `sdkconfig` — они не удаляются.

## 4. Дальше, без USB

| Что | Команда |
|---|---|
| Прошить LyraT (тот же вариант адреса) | `python lyrat_resend/tools/bench/fw.py flash --variant mac_b1` |
| Прошить S3 / обе | `fw.py flash --board s3` / `fw.py flash --board both --variant mac_b1` |
| Журнал обеих плат | `python lyrat_resend/tools/bench/udplog.py --echo` |
| Команда LyraT | `python lyrat_resend/tools/bench/s3_uart.py cmd "s"` |
| Сбросить LyraT / S3 | `s3_uart.py reboot` / `s3_uart.py restart` |
| Мощность Wi-Fi S3 (в 0,25 дБм, до перезапуска) | `s3_uart.py power 40`; видна в строке `stat` как `txp=` |
| Проверка стенда, запись звонка | `owner_check.py ...`, `call_record.py` (`OWNER_CHECK.md`) |

USB снова нужен, только если LyraT зависла (по сети её не сбросить: S3 не подключена к её EN) или обе копии прошивки
не запускаются (`OTA.md`, «back over USB»). Любой инструмент работает по-старому с ключом `--usb`.
