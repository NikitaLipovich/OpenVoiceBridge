## AT-команды FSC-BT1036 (одноразовая настройка)

```
AT+I2SCFG=3
AT+HFPSR=16000
AT+REBOOT
```

> **Не отправлять `AT+PROFILE`** — заводской `+PROFILE=1195` уже включает все нужные профили.
> `AT+PROFILE=1` = только SPP, отключает HFP.

### Почему HFPSR=16000 если телефон шлёт 8000?

OnePlus 13R не поддерживает mSBC (wide-band) и всегда договаривается до CVSD 8kHz.
Модуль сообщает это через `+HFPSR=8000` во время звонка — именно это значение реально используется.
Прошивка ESP32 настроена под 8kHz.

### Верификация после ребута

```
AT+I2SCFG?   → +I2SCFG=3    ✓
AT+HFPSR?    → +HFPSR=16000 ✓
AT+PROFILE?  → +PROFILE=1195 ✓
```

После ребута в статусе должно быть `+HFPSTAT=1` — HFP активен.

## Подключение проводов

```
FSC-BT1036x              ESP32-S3-DevKitC-1 v1.1
───────────              ──────────────────────────
  P30 (BCLK)  ─────────► GPIO 4  (левая сторона, 4й пин)
  P31 (WS)    ─────────► GPIO 5  (левая сторона, 5й пин)
  P33 (DO)    ─────────► GPIO 6  (левая сторона, 6й пин)
  GND         ──────────  GND
  VDD         ──────────  3.3V
  P15 (RST)   ── 10kΩ ──  3.3V
```

ESP32 является I2S **мастером** (генерирует BCLK и WS).
BT1036 является I2S **слейвом** (следует за клоком ESP32).

## Параметры I2S (рабочие)

| Параметр | Значение | Причина |
|----------|----------|---------|
| Sample rate | **8000 Hz** | OnePlus 13R: CVSD, не mSBC |
| Bit depth | 16 bit | AT+I2SCFG bits[3-4]=00 |
| I2S format | Philips (standard) | AT+I2SCFG bits[5-6]=00 |
| ESP32 role | Master | генерирует BCLK/WS |
| BT1036 role | Slave | AT+I2SCFG bit[1]=1 |
| Slot mode | **Stereo read** | BT1036 всегда выдаёт L+R |
| Output | **Mono (LEFT ch)** | де-интерливинг в ESP32 |

### Критический урок: stereo vs mono

BT1036 в режиме I2S slave выдаёт **стерео** поток (L+R чередованием) даже для mono HFP аудио.
Если настроить ESP32 в `I2S_SLOT_MODE_MONO` — DMA читает только часть данных → звук замедляется в 2 раза и звучит роботизированно.

**Решение:** читать стерео (`I2S_SLOT_MODE_STEREO`, 640 байт/20мс), потом в коде брать только LEFT канал (чётные индексы) → 320 байт mono.

```c
// Де-интерливинг: stereo[L0, R0, L1, R1, ...] → mono[L0, L1, ...]
for (size_t i = 0; i < mono_samples; i++) {
    mono[i] = stereo[i * 2];  // LEFT channel
}
```

## Параметры прошивки ESP32

```c
#define I2S_BCLK_GPIO     GPIO_NUM_4
#define I2S_WS_GPIO       GPIO_NUM_5
#define I2S_DIN_GPIO      GPIO_NUM_6
#define SAMPLE_RATE_HZ    8000
#define BITS_PER_SAMPLE   16
#define FRAME_MS          20
// FRAME_BYTES_STEREO = 640  (читаем из I2S)
// FRAME_BYTES_MONO   = 320  (шлём в UDP)
#define SW_GAIN           4    // программное усиление (AT+SPKVOL не работает в I2S режиме)
#define UDP_REMOTE_PORT   5004
```

**AT+SPKVOL и AT+MICGAIN не работают в I2S режиме** — громкость регулируется через `SW_GAIN` в коде.
Текущий SW_GAIN=4 хорошо слышен. Диапазон: 1–8 (выше 8 будет clipping).

## Последовательность событий при звонке (норма)

```
+HFPSTAT=5,<номер>   ← входящий звонок
+HFPRING=1           ← звонит
+HFPAUDIO=1          ← I2S активен, аудио идёт на модуль  ← КЛЮЧЕВОЕ
+HFPSR=8000          ← подтверждение rate от телефона
+HFPSTAT=6           ← звонок активен
+HFPSTAT=6,<номер>
...
+HFPAUDIO=0          ← звонок завершён, I2S остановлен
+HFPSTAT=3           ← HFP standby
```

Если `+HFPAUDIO=1` **не появляется** → аудио остаётся на телефоне. Команда принудительного переключения: `AT+HFPADTS=2`

## Проблемы которые были решены

| Проблема | Причина | Решение |
|----------|---------|---------|
| `assert failed: xRingbufferSendAcquire` | `SendAcquire` работает только с `RINGBUF_TYPE_NOSPLIT` | Заменить на `xRingbufferSend` |
| `sendto errno=12` (ENOMEM) | Неправильный UDP_REMOTE_IP, lwIP заканчивались pbufs | Поставить реальный IP ПК |
| Тишина в WAV | `+HFPAUDIO=1` не приходило → аудио на телефоне | Телефон должен переключить аудио на BT-гарнитуру |
| `AT+PROFILE=1` отключил HFP | `AT+PROFILE` — битовая маска, бит 0 = SPP, бит 3 = HFP-HF | Не трогать PROFILE, заводские 1195 правильные |
| Роботизированный замедленный звук | I2S slave выдаёт стерео, мы читали моно → двойная скорость | Читать стерео, де-интерливать LEFT канал |
| Тихий звук | AT+SPKVOL не работает в I2S режиме | SW_GAIN=4 в прошивке |

## v0.2 — Полная схема подключения (два модуля)

> Статус: в разработке
> Добавляет: вывод звонка в TRRS гарнитуру + микрофон гарнитуры обратно в телефон

### Схема

```
Телефон ←──── BT1036-A (HFP-HF) ────── I2S0 ──────── ESP32-S3 ──────── I2S1 ──────── BT1036-B ────── TRRS гарнитура
               (звонок + микрофон)    full-duplex    full-duplex       (DAC + ADC)   (наушники + mic)
                                                          │
                                                       UDP/Wi-Fi
                                                          │
                                                          ПК (WAV)
```

### Провода BT1036-A (телефонная сторона)

```
FSC-BT1036-A             ESP32-S3-DevKitC-1 v1.1
────────────             ──────────────────────────
  P30 (BCLK)  ─────────► GPIO 4
  P31 (WS)    ─────────► GPIO 5
  P33 (DO)    ─────────► GPIO 6   ← звонок с телефона (RX)
  P32 (DI)    ◄───────── GPIO 7   ← твой голос → телефон (TX)
  GND         ──────────  GND
  VDD         ──────────  3.3V
  P15 (RST)   ── 10kΩ ──  3.3V
```

### Провода BT1036-B (сторона гарнитуры)

```
FSC-BT1036-B             ESP32-S3-DevKitC-1 v1.1
────────────             ──────────────────────────
  P30 (BCLK)  ─────────► GPIO 15
  P31 (WS)    ─────────► GPIO 16
  P32 (DI)    ◄───────── GPIO 17  ← звонок → наушники (TX)
  P33 (DO)    ─────────► GPIO 18  ← микрофон из гарнитуры (RX)
  GND         ──────────  GND
  VDD         ──────────  3.3V
  P15 (RST)   ── 10kΩ ──  3.3V
```

Подключить TRRS гарнитуру (наушники + микрофон) к джеку BT1036-B.

### AT команды BT1036-B (одноразово, нет BT-пайринга)

```
AT+I2SCFG=3
AT+REBOOT
```

### Маршрутизация аудио в прошивке

| Путь | Источник | Назначение |
|------|---------|------------|
| Звонок RX | BT1036-A P33 → GPIO6 → I2S0 RX | UDP → ПК + I2S1 TX → наушники |
| Микрофон RX | BT1036-B P33 → GPIO18 → I2S1 RX | I2S0 TX → GPIO7 → BT1036-A → телефон |

### Питание

Оба BT1036 питаются от 3.3V пина ESP32 DevKit.
При brownout reset — заменить USB кабель на толстый/короткий или питать модули от внешнего источника 3.3V.
