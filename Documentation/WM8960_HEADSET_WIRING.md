# WM8960 SparkFun — Подключение TRRS гарнитуры

> Плата: SparkFun Stereo Audio Codec Breakout WM8960 (v1.0)
> Резистор: 4.68kΩ (есть в наличии, подходит вместо стандартного 2.2kΩ)

---

## Земля на плате WM8960 SparkFun

На плате **один общий GND**. В схеме он подписан по-разному (DGND, AGND, SPKGND1, SPKGND2, GNDPADDLE) — но все они соединены вместе на PCB. На разъёмах платы это просто пин **GND**.

---

## TRRS джек — что за что отвечает

```
  Tip    (1) — левый наушник (L)
  Ring1  (2) — правый наушник (R)
  Ring2  (3) — земля (GND)
  Sleeve (4) — микрофон (MIC)
```

> Стандарт CTIA/AHJ — большинство Android/ПК гарнитур.

---

## Схема подключения

```
                     ┌──────────────────────────────┐
                     │       WM8960 SparkFun         │
                     │                               │
  TRRS Tip    ───────┤ HP_L                          │
  TRRS Ring1  ───────┤ HP_R                          │
  TRRS Ring2  ───────┤ OUT3  (виртуальная земля!)    │
  ESP32 GND   ───────┤ GND                           │
                     │                               │
                     │ MICBIAS ──[4.68kΩ]──┐         │
  TRRS Sleeve ───────┤ LINPUT1 ────────────┘         │
                     │                               │
  ESP32 3.3V  ───────┤ 3.3V                          │
                     │ MCLK   (встроенный генератор) │
  ESP32 GPIO15───────┤ DCLK                          │
  ESP32 GPIO16───┬───┤ DLRC                          │
                 └───┤ ALRC  (перемычка на плате)    │
  ESP32 GPIO17───────┤ DDAT                          │
  ESP32 GPIO18───────┤ ADAT  (mic ADC output)        │
  ESP32 GPIO8 ───────┤ SDA                           │
  ESP32 GPIO9 ───────┤ SCL                           │
                     └──────────────────────────────┘
```

**Важно про OUT3** — WM8960 это "capless" дизайн наушникового усилителя. OUT3 выдаёт буферизованный VMID (~1.65V) — виртуальную землю для наушников. TRRS Ring2 (GND наушников) должен идти на OUT3, а не на GND платы. Без этого наушники либо не звучат, либо появляется постоянный DC offset.

**Важно про LINPUT1 и Sleeve** — к LINPUT1 приходят три вещи одновременно:

```
  TRRS Sleeve ──────┐
  R1 нога 1   ──────┼──── WM8960 LINPUT1
                    │
  WM8960 MICBIAS ──[4.68kΩ = R1]
```

---

## Таблица всех соединений

| Узел | Что соединяется | Примечание |
|------|----------------|------------|
| **GND** | WM8960 GND + ESP32 GND | Общая земля питания |
| **HP_L** | TRRS Tip + WM8960 HP_L | Левый наушник |
| **HP_R** | TRRS Ring1 + WM8960 HP_R | Правый наушник |
| **OUT3** | TRRS Ring2 + WM8960 OUT3 | Виртуальная земля наушников (VMID ≈1.65V) |
| **MIC** | TRRS Sleeve + WM8960 LINPUT1 + R1 нога 1 | Три точки в одном узле |
| **MICBIAS** | WM8960 MICBIAS + R1 нога 2 | R1 = 4.68kΩ |

## Список проводов

| # | От | До |
|---|----|----|
| 1 | TRRS Tip | WM8960 HP_L |
| 2 | TRRS Ring1 | WM8960 HP_R |
| 3 | TRRS Ring2 | WM8960 OUT3 |
| 4 | TRRS Sleeve | WM8960 LINPUT1 |
| 5 | TRRS Sleeve | резистор 4.68kΩ нога 1 |
| 6 | резистор 4.68kΩ нога 2 | WM8960 MICBIAS |
| 7 | ESP32 3.3V | WM8960 3.3V |
| 8 | ESP32 GND | WM8960 GND |
| 9 | ESP32 GPIO15 | WM8960 DCLK |
| 10 | ESP32 GPIO16 | WM8960 DLRC |
| 11 | WM8960 DLRC | WM8960 ALRC (перемычка) |
| 12 | ESP32 GPIO17 | WM8960 DDAT |
| 13 | ESP32 GPIO18 | WM8960 ADAT |
| 14 | ESP32 GPIO8 | WM8960 SDA |
| 15 | ESP32 GPIO9 | WM8960 SCL |

> MCLK не подключать — на плате уже стоит встроенный генератор 2MHz (Y1 + U4).
> SDA = GPIO8, SCL = GPIO9 — рабочая конфигурация.

## Замечания

- **OUT3 → TRRS Ring2** — OUT3 это виртуальная земля наушников (VMID buffer). **Не перемычить OUT3 на GND платы** — тогда наушник окажется между HP_L/HP_R и настоящей землёй, минуя виртуальный средний потенциал, и звука не будет.
- **Провода 4 и 5** оба идут от TRRS Sleeve — скрутить их вместе и припаять к одной точке, затем от этой точки один провод до LINPUT1, второй до ноги резистора.
- **4.68kΩ вместо 2.2kΩ** — нормально, ток ~0.36mA допустим для электретного микрофона. Если тихо — компенсируется в прошивке.
- **SPKVDD, VIN, LINPUT2/3, RINPUT1/2/3, SPK_LP/LN/RP/RN** — не используются, оставить свободными.
